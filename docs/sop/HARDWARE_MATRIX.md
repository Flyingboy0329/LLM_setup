# 🛠️ NVIDIA 本地 AI 自動化部署矩陣 (IE 標準作業程序 SOP)

本指南旨在為不同硬體規格的用戶提供免調整的本地 LLM 最佳化部署範式。所有模型請至專案 Discord 討論串獲取推薦 GGUF 下載連結，下載後直接置入 `./Models/` 資料夾即可啟動。

## 防呆與系統安全守則 (Poka-Yoke)
1. **遊戲與語音優先**：背景進程預設降級為 `BELOW_NORMAL_PRIORITY_CLASS`，保障 Riot Vanguard 反作弊與遊戲畫面 100% 流暢。
2. **ngrok 資訊安全**：請於設定檔中妥善保護你的管理員金鑰，勿將包含敏感個人隱私的本地資料暴露於公網鏈路。
